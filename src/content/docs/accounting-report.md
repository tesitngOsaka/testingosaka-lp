# 「寄付金」の会計報告について

お預かりした寄付金は「現金出納帳」として記録し、コミュニティの維持・運営のために適切に管理・使用いたします。
運営の透明性を高めるため、イベントごとに集計結果をconnpassの参加者向け全体メールにてご報告いたします。
本ページの末尾に、実際に送信するメールの文面例を掲載しています。
## 管理体制

お預かりした現金は、会計担当（現在はやまずん）が責任を持って管理します。
詳細な入出金を記録した「現金出納帳」は、実行委員会のメンバーにのみ共有され、コミュニティの資産として適切に管理されていることを相互に確認します。

## 主な使途と支出のルール

お預かりした寄付金は、コミュニティの継続的な活動を支えるために、主に以下の目的で使用されます。

- 付箋・ペン・名札等の備品
- Webページのサーバー代
- その他、必要に応じて拠出(会場費等)

寄付金からの支出は、実行委員会の[コンセント（同意）](/docs/consent)によって決定されます。
これにより、支出がコミュニティ全体の利益に繋がることを確認します。

なお、コミュニティの懇親会等における飲食費については、参加者各自の負担を原則とし、寄付金からの支出は行いません。
また、登壇者や実行委員への謝礼として使用することもありません。当コミュニティの活動は、メンバーの自発的な貢献によって成り立っています。

## 残高報告について

イベントごとの収入報告は上記のとおり実施しますが、コミュニティ全体の資産（寄付金の残高）を定期的に（例：半期や通期で）公開することについては、現在のところ未定です。
これは、報告の手間や方法について、まだコミュニティ内で十分な議論ができていないためです。会計の透明性に関する方針は、今後の活動を通じて継続的に検討していきます。

## 報告メールの例

---

**件名:**
【ご報告】先日のイベントの御礼と「寄付金」集計結果について

**本文:**
testingOsakaにご参加いただいた皆様

先日のイベントではご参加いただき、誠にありがとうございました。

当コミュニティでは、継続的な運営を目的とした「寄付金（運営支援）」を受け付けております。
趣旨や詳細につきましては、以下のガイドラインページに掲載しております。
https://testingosaka.org/docs/donation/

運営の透明性を高めるため、今回の集計結果を以下の通りご報告いたします。

【今回の集計結果】
合計： xxxx円

ご協力いただいた皆様、誠にありがとうございました。
お預かりした寄付金は、備品代等の一部に充当させていただきます。

今後ともtestingOsakaをよろしくお願いいたします。
